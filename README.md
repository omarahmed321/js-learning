## About

This repository contains early programming practice tasks created while learning core JavaScript syntax. It focuses on handling user input via dialog boxes, applying control flow rules, and logging calculated outputs.

## Data Storage and Architecture

The project runs entirely in memory on the client side. User inputs are collected temporarily through browser prompts without persistent storage or backend dependencies.

## Features

- **Grade Evaluation Logic**: Evaluates numeric scores and attendance bonuses to determine passing marks and letter grades.
- **Interactive Prompts**: Captures user input using native browser prompt and confirm dialogs.
- **Button Event Binding**: Triggers specific JavaScript functions directly through HTML click attributes.

## Run Locally

### Prerequisites

You only need a modern web browser.

### Execution

1. Clone the repository:
```bash
git clone https://github.com/omarahmed321/js-learning.git
```

2. Navigate to the directory:
```bash
cd js-learning
```

3. Open index.html in your browser:
```bash
xdg-open index.html
```
